# A11yPilot Studio

A11yPilot Studio 是一个 AI 无障碍审计与修复工作台，面向前端项目和组件库。

## 项目能力
- 读取 React/Vue 组件、Storybook、Playwright 录制、axe 报告、键盘导航日志和设计标注
- 识别 WCAG 风险、键盘路径问题、ARIA 状态缺口和视觉状态问题
- 生成组件修复 patch、Playwright/axe 回归测试和 PR 审查报告
- 输出验证矩阵、影响范围、风险等级和后续改进计划

## 部署方式
这是一个静态 HTML demo，可以直接部署到 GitHub Pages、Netlify、Vercel 或任意静态托管平台。
